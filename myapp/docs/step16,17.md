rails db:seed

### ステップ17: ログイン/ログアウト機能を実装しよう

- 追加のGemを使わず、自分で実装してみましょう
  - DeviseなどのGemを使わないことで、HTTPのCookieやRailsにおけるSessionなどの仕組みについて理解を深めることが目的です
  - また、一般的な認証についての理解を深めることも目的にしています（パスワードの取り扱いについてなど）
- ログイン画面を実装しましょう
https://railstutorial.jp/chapters/log_in_log_out?version=4.2#sec-sessions_and_failed_login
rails generate controller Sessions new
###### 
 rails generate migration add_password_digest_to_users password_digest:string
 rails db:migrate

https://qiita.com/kents1002/items/3015d60b91e6b03d5ffa
###### Railsでパスワードの取り扱い
https://qiita.com/chobi9999/items/20b962a324a0bdbfc0dc
###### 暗号化されたパスワードはpassword_digestというカラムに保存される
